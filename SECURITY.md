# Security

Please report a suspected vulnerability privately, by email to `SECURITY-CONTACT-TO-BE-SET-BY-THE-FOUNDERS`, with
`[security]` at the start of the subject. Don't open a public issue for it.

Say which commit or version it affects and how to reproduce it. Use test keys only, never a key in real use, and never
send a real API key, signing key or customer record.

The kit is in design and nothing is built yet, so there is no supported release. Once there is, this file will list
the versions that receive fixes.
